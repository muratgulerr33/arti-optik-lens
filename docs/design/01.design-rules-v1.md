## 2. Theme & Tokens (Source of Truth)

### 2.1 Dark Mode "Source of Truth"

**Selector Pattern:**
- Dark mode **class-based**: `html` (documentElement) üstünde `dark` class'ı
- **Tailwind v4** için `globals.css` içinde:
  ```css
  @custom-variant dark (&:where(.dark, .dark *));
  ```

**Token Yapısı:**
- Light: `:root { ... }`
- Dark: `:root.dark { ... }` (özellikle belirt: `.dark` değil `:root.dark` kullanılıyor)

**Background Mapping:**
- `--background` ana token
- `--color-background: var(--background)` mapping'i hem light hem dark scope'ta mevcut
- Bu mapping Tailwind `@theme` bloğunda tanımlı: `--color-background: var(--background);`

**Color Scheme:**
- `:root { color-scheme: light; }`
- `:root.dark { color-scheme: dark; }`

**Evidence:** `src/app/globals.css` (lines 3-4, 66-127, 127-183)

## 3. Dark Mode (Tailwind v4 + next-themes)

### 3.1 next-themes Configuration

**Provider Setup:**
```tsx
<ThemeProvider
  attribute="class"
  defaultTheme="system"
  enableSystem
  disableTransitionOnChange
>
```

**Critical Settings:**
- `attribute="class"`: HTML element'e `dark` class'ı eklenir
- `defaultTheme="system"`: Sistem tercihine göre başlar
- `enableSystem`: Sistem tercihi takip edilir
- `disableTransitionOnChange`: Theme değişiminde transition yok (göz yormayı engeller)

**Evidence:** `src/components/theme/theme-provider.tsx`, `src/app/layout.tsx`

---

### 3.2 Theme Toggle Stabilizasyonu (Spam Click Fix)

**Problem:** Toggle butonu hızlı tıklamada tutarsız hissetmesin.

**Çözüm:**
1. `toggleLocked` state ile **geçici kilit** (250ms)
2. Kilitliyken button `disabled` + isteğe bağlı `Switching…` UI
3. Toggle kararı için DOM state okunur:
   ```tsx
   const isCurrentlyDark = typeof document !== 'undefined' && 
     document.documentElement.classList.contains("dark")
   setTheme(isCurrentlyDark ? "light" : "dark")
   ```

**Implementation:**
```tsx
const [toggleLocked, setToggleLocked] = useState(false)

const toggleTheme = () => {
  if (toggleLocked) return
  
  const isCurrentlyDark = typeof document !== 'undefined' && 
    document.documentElement.classList.contains("dark")
  
  setToggleLocked(true)
  setTheme(isCurrentlyDark ? "light" : "dark")
  
  setTimeout(() => {
    setToggleLocked(false)
  }, 250)
}
```

**Evidence:** `src/app/design/page.tsx` (lines 16, 107-124)

## 4. Hydration-safe Rendering (Next.js + next-themes)

### 4.1 Mounted Pattern

**Problem:** SSR/CSR mismatch olmaması için theme'e bağlı UI/text üretme.

**Çözüm:**
```tsx
const [mounted, setMounted] = useState(false)

useEffect(() => {
  setMounted(true)
}, [])

if (!mounted) {
  return <div className="min-h-screen bg-background" />
}

// Artık theme'e bağlı render yapılabilir
const isDark = mounted && resolvedTheme === "dark"
```

**Kullanım:**
- `Espresso / Pudra` gibi theme'e bağlı label'lar:
  ```tsx
  <span suppressHydrationWarning>
    {mounted ? (isDark ? "Espresso" : "Pudra") : "Pudra"}
  </span>
  ```
- İlk SSR render ile ilk client render aynı olmalı (hydration mismatch olmamalı)

**Manuel DOM Manipülasyonu:**
- Manuel `classList.toggle` yok; theme değişimi `next-themes` üzerinden yapılır.

**Evidence:** `src/app/design/page.tsx` (lines 15, 27-30, 100-103, 202-204)

## 5. Interaction Rules (2026 "native app feel")

### 5.1 Touch Target (44px Minimum)

**Kural:** Minimum hit area: **44px** (WCAG 2.5.5)

**Button Implementation:**
- Default yükseklik: `min-h-11 h-11` (44px)
- Küçük boyutlarda "hit-area expansion" yaklaşımı:
  ```tsx
  // xs size: görsel 24px, hit area 44px
  size="xs": "min-h-11 h-6 ... before:absolute before:inset-[-8px] before:content-[''] before:pointer-events-none"
  // sm size: görsel 32px, hit area 44px
  size="sm": "min-h-11 h-8 ... before:absolute before:inset-[-6px] before:content-[''] before:pointer-events-none"
  ```
- Icon button'larda da min 44x44: `size="icon": "min-w-11 min-h-11 size-11"`

**Input Implementation:**
- Default yükseklik: `min-h-11 h-11` (44px)

**Checkbox/Switch/Radio Implementation:**
- Root hit area: `size-11` (44x44px) - minimum touch target
- **Root is 44px hit-area (no border/bg). Inner 16px box is the visual border/bg.**
- Root = 44px hit-area (visual yok), inner = 16px visual box (border/bg var; unchecked'te de görünür).
- Görsel kutu küçük kalabilir (örn: indicator `size-4` = 16px) ama root gerçekten 44x44 olmalı
- Pseudo-element ile hit area büyütme yöntemi kullanılmamalı; `getBoundingClientRect()` büyümeyeceği için test script'i fail verir
- Visual box görünürlük token'ları (final implementation):
  - **Unchecked:** `bg-muted/25 dark:bg-muted/15` + `border-foreground/15 dark:border-foreground/20` (light ve dark modda net görünür)
  - **Checked:** `bg-primary border-primary text-primary-foreground` (icon görünür)
  - **Disabled:** `bg-muted/10 dark:bg-muted/10` + `border-foreground/10 dark:border-foreground/10` + `opacity-60` (görünür ama soluk)
- Pattern:
  ```tsx
  // Root 44x44 hit-area (NO border/background), inner 16px visual box (WITH border/background)
  <Root className="size-11 flex items-center justify-center outline-none focus-visible:ring-[3px] focus-visible:ring-ring/50 ...">
    <VisualBox className="size-4 rounded-[4px] border border-foreground/15 dark:border-foreground/20 bg-muted/25 dark:bg-muted/15 shadow-xs transition-[colors,box-shadow] group-data-[state=checked]:bg-primary group-data-[state=checked]:border-primary group-data-[state=checked]:text-primary-foreground group-disabled:bg-muted/10 dark:group-disabled:bg-muted/10 group-disabled:border-foreground/10 dark:group-disabled:border-foreground/10 group-disabled:opacity-60">
      <Indicator>...</Indicator>
    </VisualBox>
  </Root>
  ```

**Evidence:** `src/components/ui/button.tsx` (lines 24-31), `src/components/ui/input.tsx` (line 11), `src/components/ui/checkbox.tsx` (lines 17, 24)

### 5.2 Focus Ring / Outline Sistemi (Tek Sistem, Tutarlı)

**Global Baseline:**
```css
*:focus-visible {
  outline: 1px solid var(--focus-outline);
  outline-offset: 2px;
}
```

**Component Seviyesinde:**
- Button/Input `focus-visible:ring-2` + `ring-offset` + outline
- Pattern:
  ```tsx
  "focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-2 focus-visible:ring-offset-background"
  ```

**Token'lar:**
- `--ring-foreground`: Ring içindeki text rengi
- `--ring-offset`: Ring ile element arasındaki boşluk rengi
- `--focus-outline`: Subtle outline (dark mode clarity için)

**Prensip:**
- "Keyboard kullanıcı" için ring her zaman görünür
- Mouse click ile her zaman zorunlu değil (`focus-visible`)

**Evidence:** `src/app/globals.css` (lines 196-200), `src/components/ui/button.tsx` (line 8), `src/components/ui/input.tsx` (line 13)

### 5.3 Hover / Pressed / Disabled

**Hover Overlay:**
- Light: `--hover-overlay: oklch(0 0 0 / 0.05)`
- Dark: `--hover-overlay: oklch(1 1 1 / 0.05)`
- Kullanım: `hover:bg-accent` veya component-specific hover states

**Pressed Overlay:**
- Light: `--pressed-overlay: oklch(0 0 0 / 0.1)`
- Dark: `--pressed-overlay: oklch(1 1 1 / 0.1)`
- Micro feedback: `active:scale-[0.99]` veya `active:scale-95`
- Shadow/elevation davranışı: `active:shadow-sm` (hover'dan daha az shadow)

**Disabled:**
- `--disabled-opacity: 0.6`
- Kullanım: `disabled:opacity-[var(--disabled-opacity)]`
- Cursor: `disabled:cursor-not-allowed`
- Pointer events: `disabled:pointer-events-none`

**Evidence:** `src/app/globals.css` (lines 105-107, 163-165), `src/components/ui/button.tsx` (line 8)

### 5.4 Motion

**Motion Token'ları:**
- Duration:
  - Fast: `--motion-duration-fast: 120ms` (pressed micro-interactions)
  - Default: `--motion-duration: 180ms` (standard transitions)
  - Slow: `--motion-duration-slow: 240ms` (complex animations)
- Easing:
  - Out: `--motion-ease-out: cubic-bezier(0.16, 1, 0.3, 1)` (native-ish)
  - In: `--motion-ease-in: cubic-bezier(0.7, 0, 0.84, 0)`
  - In-Out: `--motion-ease-in-out: cubic-bezier(0.65, 0, 0.35, 1)`

**Kullanım:**
```tsx
// Tailwind classes
"transition-[colors,box-shadow,transform] duration-motion ease-motion-out"
"active:transition-transform active:duration-motion-fast"
```

**Reduced-motion Desteği:**
- macOS eşlemesi: **Erişilebilirlik → Ekran → "Hareketi azalt"** = CSS `prefers-reduced-motion: reduce`
- Global CSS ile otomatik uygulanır:
  ```css
  @media (prefers-reduced-motion: reduce) {
    *,
    *::before,
    *::after {
      animation-duration: 0.01ms !important;
      animation-iteration-count: 1 !important;
      transition-duration: 0.01ms !important;
      scroll-behavior: auto !important;
    }
  }
  ```
- Butonlarda hover/press micro-motion varsa, reduced-motion'da "yumuşar" (0.01ms)

**Evidence:** `src/app/globals.css` (lines 109-115, 167-173, 203-212), `src/components/ui/button.tsx` (line 8)

## 7. Testing & Troubleshooting

### 7.1 Console Doğrulama (Copy/Paste)

**Light / Dark Farkı:**
```javascript
// Dark mode aktif mi?
document.documentElement.classList.contains("dark")

// Background token değeri
getComputedStyle(document.documentElement).getPropertyValue("--background").trim()

// Color-background mapping değeri
getComputedStyle(document.documentElement).getPropertyValue("--color-background").trim()
```

**Token Sync Kontrolü:**
```javascript
const bg = getComputedStyle(document.documentElement).getPropertyValue("--background").trim()
const colorBg = getComputedStyle(document.documentElement).getPropertyValue("--color-background").trim()
console.log("Sync:", bg === colorBg ? "✓" : "✗")
```

**Not:** CSS'te oklch kullansak bile browser computed output'u `lab(...)` döndürebilir; bu normal (color conversion).

**44px Touch Target Doğrulama:**
```javascript
// /design sayfasında console'da çalıştır
const interactive = document.querySelectorAll('button, input, [role="button"], [role="checkbox"], [role="radio"], a[href], [tabindex]:not([tabindex="-1"])')
const offenders = []
interactive.forEach(el => {
  const rect = el.getBoundingClientRect()
  const min = Math.min(rect.width, rect.height)
  if (min < 44 && rect.width > 0 && rect.height > 0) {
    offenders.push({
      id: el.id || el.className,
      size: `${Math.round(rect.width)}x${Math.round(rect.height)}`,
      min: Math.round(min)
    })
  }
})
console.log(`44px altı: ${offenders.length}`, offenders.length === 0 ? '✓' : offenders)
// Beklenen: "44px altı: 0 ✓"
```

### 7.3 Yaygın Sorunlar

**Hydration Mismatch:**
- **Sebep:** Theme'e bağlı render SSR'da farklı, CSR'da farklı
- **Çözüm:** `mounted` pattern kullan, `suppressHydrationWarning` ekle

**Toggle Tutarsızlığı:**
- **Sebep:** Hızlı tıklamada state race condition
- **Çözüm:** `toggleLocked` state ile 250ms kilit

**Token Mapping Hatası:**
- **Sebep:** `--color-background` mapping'i eksik veya yanlış scope'ta
- **Çözüm:** Hem `:root` hem `:root.dark` içinde `--color-background: var(--background);` olmalı

**Focus Ring Görünmüyor:**
- **Sebep:** `focus-visible` yerine `focus` kullanılmış
- **Çözüm:** `focus-visible:ring-2` kullan, `focus:` değil
